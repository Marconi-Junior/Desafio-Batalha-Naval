# Desafio Batalha Naval

Após a inicialização:
- O programa irá imprimir na tela o tabuleiro de Batalha Naval 10x10;
- No tabuleiro terá '0' para indicar 'água' e '3' pata indicar 'barco';
- O tabuleiro terá um barco tomando 3 casas na horizontal e 3 casas na vertical;
- O programa irá encerrar após a exibição do tabuleiro com os 2 barbos.
